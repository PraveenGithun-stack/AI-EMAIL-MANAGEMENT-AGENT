AI Email Management Agent

Project Overview

An AI-powered email management automation system built using n8n, Gmail, and OpenAI.

The workflow processes incoming emails, classifies them, detects priority, generates summaries, and creates contextual reply drafts.

Technologies Used

- n8n
- Gmail
- OpenAI

Key Features

- Automatic email processing
- AI-based email classification
- Priority detection
- Email summarization
- Context-aware reply generation
- Automated Gmail draft creation

Workflow Architecture

1. Gmail Trigger
2. Edit Fields
3. Get a Message
4. AI Agent
5. OpenAI Chat Model
6. Structured Output Parser
7. Gmail Create a Draft
